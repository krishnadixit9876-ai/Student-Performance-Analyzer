# Project Statement

## Project Title

**Student Performance Analyzer**

## Problem Statement

Managing student academic information manually can be time-consuming and may make it difficult to analyze overall student performance.

Student details, marks, attendance and performance information may be maintained separately, making it difficult to quickly calculate percentages, grades, attendance status and class-level statistics.

The Student Performance Analyzer provides a Java-based solution to manage this information in a structured manner and generate useful performance reports.

## Project Scope

The project focuses on managing and analyzing the academic performance of students.

The system includes:

* Student information management
* Subject-wise marks management
* Attendance management
* Individual performance report generation
* Class performance statistics
* Topper identification
* Pass/fail statistics
* Grade-wise statistics
* Input validation and error handling
* MySQL database storage

The current version is designed as a console-based Java application.

## Target Users

The primary target users of the system are:

* Teachers
* Faculty members
* Academic administrators
* Educational institutions

The system can help users maintain student academic records and obtain performance-related information efficiently.

## High-Level Features

### Student Management

The system provides functionality to:

* Add students
* View students
* Search students
* Update student information
* Delete students

### Marks Management

The system provides functionality to:

* Add subject-wise marks
* View marks
* Update marks
* Delete marks
* Calculate total marks
* Calculate percentage
* Calculate grades
